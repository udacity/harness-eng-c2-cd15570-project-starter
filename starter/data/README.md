# Data Sets

- `synthetic_dealer_inventory.csv`: current dealer stock.
- `synthetic_vehicle_history.csv`: historical ownership and reliability data.
- `vehicle_sales_reviews.csv`: sales transactions and owner reviews for data-quality analysis.

Use the `data_quality_report` tool before performing statistical analysis on
`sales_reviews`. The dataset intentionally includes realistic recording and
standardization issues for the harness to detect and explain.
